# Line profiles

Choose one profile per output. Do not blend every reference into one average line style.

## soft-crayon-outline (default)

Use for playful characters, objects, tools, delivery, work, and small visual jokes. Draw a dominant black outer silhouette with tactile, softly rounded strokes and lightly textured edges. Give each contour a believable start and finish: touch down lightly, widen on a shoulder, shoe, turn, or push, then release into a gentle taper or a small soft pause. Keep selected edges open; let adjacent strokes nearly meet, overlap briefly, or stop before closure rather than tracing a closed cartoon shape. Do not end every mark with the same round stamp. Keep inner details short and thin. Add one small solid black patch only when it clarifies weight. This is the closest default to the tactile, broad black outlines in the supplied reference family.

## fine-gesture

Use for quiet, delicate, airy vignettes: a lone figure, a landscape arc, a small moon, a small action. Draw with a single thin but still pressure-sensitive graphite-like line. Permit open loops and wandering arcs, but retain a firm, readable gesture. Do not use this profile for a mechanical object with many parts unless it is radically simplified.

## ink-silhouette

Use when the joke depends on a strong black mass: clothing, hair, a parcel, or an animal marking. Combine a few thin spontaneous contour lines with 1–3 rounded solid black shapes. Keep the solid shapes irregular and touchable, never glossy or perfectly geometric.

## Selection rule

If supplied references visibly contain a chunky black contour around people/objects, select `soft-crayon-outline`; do not weaken it into generic pencil. If they are mostly airy loops and a tiny subject, select `fine-gesture`. If both appear in the reference set, choose based on the requested subject—not both in the same drawing unless the user asks for a hybrid.
